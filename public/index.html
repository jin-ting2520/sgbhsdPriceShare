  1. 选择区服：输入区服名称（如 S1、008服），支持从历史区服中快速选择。
  2. 选择城池：必选项，下拉搜索；输入新城池名称后按 Enter 即可写入字典表。
  3. 选择商品：可选项，留空时商品列固定展示全部商品；输入新商品名称后按 Enter 即可写入字典表。
  4. 点击查询：区服与城池将填充进列表，买价/卖价从数据库带出，查不到价格显示 “-”。
  5. 填写价格：直接在买价/卖价输入框中录入数字，可用「同上一行」快速复制。
  6. 点击保存：表格右上角「保存」按钮 → 弹窗确认变更明细 → 确认后写入数据库。
  7. 字典管理：右上角「字典管理」可新增/重命名/停用/删除 城池、商品、区服（已被引用的项不可删除）。

清空输入

区服输入框、城池/商品下拉框均支持一键清空（右侧 × 按钮），清空后可重新选择。

快捷键

Ctrl / Cmd + Enter 快速保存；Tab 在各输入框间顺序移动；Esc 关闭弹窗。

批量导入

「批量导入」支持粘贴“商品 + 买价 + 卖价”多行数据（制表符/逗号/空格分隔），未知商品可自动创建。

更新日志

「更新日志」记录每次买价/卖价的变更前后值与时间，便于回溯价格走势。
